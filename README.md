# L’Agence tous risques · Comprendre le modèle DISC

Présentation interactive (HTML/CSS/JS autonome) pour un atelier de management : le modèle DISC illustré par les quatre personnages de l’Agence tous risques.

- 5 parties, 22 diapositives, navigation clavier / tactile, sommaire, plein écran, impression PDF.
- Fichier unique `index.html`, photos intégrées, aucune dépendance serveur.

Les profils DISC présentés sont des interprétations pédagogiques de personnages de fiction, pas des résultats de tests.
